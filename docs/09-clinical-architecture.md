# Gahai HMS Clinical Architecture

## Overview

The Clinical Architecture provides a unified framework for all healthcare services delivered through Gahai HMS.

The architecture supports:

* OPD
* IPD
* Dental
* Orthodontics
* Implants
* Pathology
* Future Specialties

while maintaining a common patient journey.
