# Gahai HMS Master Data Dictionary

## Core Entities

### Tenant

Top-level organizational owner.

### Branch

Physical healthcare location.

### Department

Operational business unit.

### User

System actor.

### Patient

Primary healthcare subject.

### Encounter

Healthcare interaction.

### Case

Long-term treatment grouping.

### Treatment Plan

Clinical roadmap.

### Charge

Financial obligation.

### Payment

Financial transaction.

### Ledger Entry

Immutable accounting record.

### Inventory Item

Physical stock item.

### Pharmacy Item

Medicine inventory item.

### Workflow

Business process.

### Task

Assigned work item.

### Document

Patient-related file.

### Report

Clinical document.

### Communication

Call, message, or notification.

### Patient Event

Timeline record.

---

## Guiding Principle

Every new module must align with the enterprise architecture and reuse existing platform services rather than creating duplicate business entities.
