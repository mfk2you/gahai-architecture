# Gahai HMS Workflow Engine

## Overview

The Workflow Engine provides a centralized framework for approvals, tasks, reminders, escalations, and business process automation.

Specialty modules do not create independent workflow systems.

All workflows use the shared platform engine.

---

## Core Components

### Workflow

Defines a business process.

### Workflow Instance

Live execution of a workflow.

### Task

Action assigned to a user.

### Approval

Authorization decision.

### Reminder

Automated notification.

### Escalation

Automatic elevation of unresolved tasks.
